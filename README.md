# 单卷恢复控制台(volume-recovery)

虚拟机数据盘尚未恢复完,值班员需要立刻恢复业务读写。本服务提供单卷恢复页:

- **4 KiB 块读写**:本地块用 SQLite 持久化(`<DATA_DIR>/volume.db`);本地缺块时从**内置只读备份镜像**读透;
- **后台回填**:网页一键启动,后台线程把缺块从备份拷贝到本地,页面实时显示进度;
- **按块挂起/放行**:网页可挂起指定块的后台备份读取;挂起期间同一块的**整块写入照常提交**,
  迟到的备份数据(`INSERT OR IGNORE` + 落盘前复查挂起表)**不会覆盖**已提交的业务写入;
- **慢读竞争语义(本次重点)**:缺块读可用 `?delay=` 模拟备份端慢读,慢读期间写入、断开、重置均可并发;
- **重启续传**:已落盘的块、断开标志保存在 SQLite 中,进程重启后保留,且未完成的回填**自动继续**;
- **断开保护**:只要还有缺块就**拒绝断开备份**(HTTP 409);补齐后允许断开,断开后数据盘纯本地读写。

## 慢读竞争:已实现的行为

缺块读走备份读透时,真正的 `pread` 在锁外执行,并用在途计数器 `_inflight` 跟踪:

1. **等待期间写入照常提交**:慢读不持有任何锁,业务整块写入随时落盘;块补齐后即可断开,
   **断开不需要等慢读返回**——`disconnect()` 只置持久标志位,有在途读时立即返回成功并提示数量。
2. **镜像句柄延迟释放**:断开时若仍有在途备份读,fd 保持打开;最后一个在途读在 `finally` 中
   发现"已断开且在途归零"才 `close(fd)`。状态接口实时暴露 `inflight_backup_reads` 与 `backup_fd_open`。
3. **断开后新读只访问本地**:断开标志置位后不会再打开镜像;本地缺块直接返回 410,回填启动返回 409。
4. **在途读结束后复查本地(不返回备份旧内容)**:备份读成功返回后,先校验请求世代再查本地——
   等待期间块已补齐(回填或业务写)就返回**本地内容**,统计 `local_after_wait`;
   **即使备份读失败也一样复查本地**,本地有块照样成功,只有本地也没有时才返回 502。
5. **重置世代(epoch)**:每次 `reset()`/`stop()` 递增请求世代;跨越重置的在途读回来后一律作废,
   接口返回 **409 并提示重试**——哪怕同号块已被重新写入(新请求不受影响,正常读新数据),统计 `stale_rejected`。
6. **断开状态持久化**:`backup_disconnected` 存于 SQLite meta 表,重启后仍是断开状态,
   不会自动续回填,缺块读保持 410。

## 运行

### Docker Compose(交付方式)

```bash
docker compose up --build
# 打开 http://localhost:8080
```

- 容器内 `/app/backup.img` 为构建期生成的只读备份镜像(256 块 × 4 KiB = 1 MiB);
- compose 将运行参数覆盖为 `BLOCK_COUNT=32`、`BACKFILL_DELAY=0.02`,小卷+短间隔便于
  值班员**重复演示慢读竞争**(镜像仍是 256 块,运行时只用前 32 块,内容可由块号推导);
- 本地块存于命名卷 `recovery-data` 中的 SQLite,`docker compose restart` 后保留并自动续传。

### 本地直跑(开发/自测)

```bash
pip install -r app/requirements.txt
python3 app/app.py          # http://localhost:5000
```

可用环境变量:`BLOCK_SIZE`(默认 4096)、`BLOCK_COUNT`(默认 256)、`BACKFILL_DELAY`(默认 0.05s/块)、
`DATA_DIR`、`BACKUP_IMAGE`、`PORT`。

## 网页演示

页面顶部为状态卡与进度条(新增**在途备份读**、**等后改取本地**、**重置后旧读作废**计数);
中部为块网格(灰=缺失,绿=本地·回填,蓝=本地·业务写入,黄=已挂起),块操作面板新增
**慢读按钮与秒数输入框**(对缺块读透生效,模拟备份端慢响应,请求在途时页面仍可写入/断开/重置);
底部提供两套一键演示:

**演示①(挂起/回填/断开)**:重置 → 挂起块 7 → 回填 → 挂起期间读被拒(409)/整块写入成功 →
缺块时断开被拒(409)→ 放行补齐 → 业务数据不被迟到备份覆盖 → 断开 → 断开后读写正常。

**演示②(慢读补齐/断开/重置作废)**:

1. 重置后对缺块 7 发起 8s 慢读,状态卡可见在途=1;
2. 慢读等待期间启动回填并对块 7 整块写入补齐(写入不被慢读阻塞);
3. 不等待慢读直接断开成功,在途计数仍为 1、句柄仍打开;
4. 断开后的新读只走本地;
5. 旧慢读返回 **local/business 的新数据**(不是备份旧内容),在途归零、句柄自动释放;
6. 再发一个慢读,等待期间重置卷并重写同号块 9;
7. 旧读返回 **409 提示重试**,重新发起读取正常拿到重写内容。

**重启持久化演示**:回填进行中执行 `docker compose restart`,刷新页面可见已落盘块保留、
回填自动继续(`GET /api/status` 的 `resumed_on_boot=true`);断开后重启则保持断开。

## API 一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/status` | 总块数/已落盘/缺失/进度/回填与备份状态/在途读数/句柄状态/统计 |
| GET | `/api/blocks` | 已落盘块及来源、挂起列表 |
| GET | `/api/block/<i>` | 读块:本地命中 / 缺块读透备份 / 挂起 409 / 断开且缺失 410 / 等待期重置 409(stale)/ 备份失败且无本地 502 |
| GET | `/api/block/<i>?delay=秒` | 模拟备份端慢读(0~120s,仅对真正走备份读透的缺块读生效;本地命中立即返回) |
| POST | `/api/block/<i>/write` | 整块写入(`{"data": "..."}`,UTF-8 ≤ 4096 B,补 0 凑整块) |
| POST | `/api/block/<i>/suspend` · `/resume` | 挂起 / 放行该块的后台备份读取 |
| POST | `/api/backfill/start` | 启动后台回填(已断开备份则 409) |
| POST | `/api/disconnect` | 断开备份:有缺块则 409 拒绝;补齐后立即断开,在途读不阻塞,句柄延迟释放 |
| POST | `/api/reset` | 清空本地卷并递增请求世代(演示用) |

## 关键设计

- **读路径三段式**:进锁记录 `epoch` 并查本地/挂起/断开状态 → 锁外备份读(可慢)→
  回锁先比 `epoch`(stale 作废)再查本地(补齐则改取本地),保证旧请求不可能返回备份旧内容。
- **在途计数与句柄生命周期**:`_inflight_cond` 复用主锁;每个镜像 fd 维护独立引用计数
  `_fd_users`,断开/世代变更时把当前 fd 放入 `_retired_fds` 退休——仍有读者就保留到
  最后一个读者在 `finally` 中回收,无读者当场关闭;新旧世代各用各的 fd,不会误关对方句柄;
  `close()` 先等在途排空再关 fd,并有退休表兜底关闭。
- **迟到备份数据不覆盖业务写入**:回填落盘用 `INSERT OR IGNORE`;取数到落盘之间业务写入
  已提交则丢弃回填结果(统计 `late_ignored`);落盘前还复查挂起表。
- **挂起语义**:挂起只影响*后台*备份读取;缺块且被挂起时业务读返回 409;整块写入不受影响。
- **持久化**:块、挂起表、回填运行标志、断开标志全部在 SQLite(WAL);重启后按标志自动续传。
- **断开条件**:`missing > 0` 时断开返回 409;断开后新读纯本地,不会再打开镜像。

- **pytest 16 项全部通过**(`python3 -m pytest tests/ -v`,连跑 4 轮稳定):
  - 原有 7 项:读透不落盘、回填至完成、挂起期读拒/写可提交/业务数据不被覆盖、
    缺块拒绝断开+补齐后断开+断开后可读写、跨重启保留块并自动续传、写入校验、并发写入不被覆盖;
  - 新增 9 项:慢读期间补齐后旧读返回本地新数据、慢读在途时断开不阻塞且句柄延迟释放、
    备份读失败仍回退本地、等待期重置旧读 stale(同号块重写也提示重试)、
    HTTP 映射(stale→409 / gone→410 / error→502)、断开状态跨重启保留、delay 参数校验、
    断开后在途慢读期间重置的旧 fd 回收、5 轮断开/重置循环的进程级 fd 泄漏检测(`/proc/self/fd`)。
- **真实 HTTP 冒烟**(独立进程 + urllib 并发脚本,25 项断言全过):完整复现

  句柄自动释放 → 等待期重置后旧读 409、新读正常 → 参数校验。
